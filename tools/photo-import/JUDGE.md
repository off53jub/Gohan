# 食事の判定（ごはん帖の取り込み）

個人の写真です。人物について報告に書かないでください。

## 材料
- `D:\GohanImport\meals.json`: 食事の一覧。各要素に id・date（撮った時刻, +09:00）・lat/lon・acc（位置の誤差 m）・address（住所）・candidates（近くのお店。OpenStreetMap。name・dist（m）・kind・cuisine・floor）。candidates が無い食事もある。
- `D:\GohanImport\meals\<id>.jpg`: 食事ごとの画像（料理の写真を最大 4 枚、看板など最大 2 枚。各マスの上に「写真番号 料理/看板など 日時」）。Read で見る。

## 決めること（食事ごとに）
アプリの AI と同じ決まり:
1. is_meal: 食事・飲み物なら true。人・風景だけなら false。
2. eaten_out: お店で食べたら true。家の食卓・手料理・コンビニの持ち帰り・ホテルの部屋らしければ false。
3. genre: 次から 1 つ: ラーメン, つけ麺, そば・うどん, 寿司, 和食, 定食, 丼, 焼肉, 焼き鳥, 居酒屋, 中華, 韓国料理, カレー, エスニック, イタリアン, フレンチ, 洋食, ハンバーガー, ファストフード, カフェ, スイーツ, パン, バー, 鍋, お好み焼き, その他
   - どんぶりに麺と汁: ちぢれ麺・黄色い麺・チャーシュー・メンマ・海苔・ねぎ・なると・味玉 → ラーメン。太く白い麺 → うどん、灰色や茶色の細い麺 → そば（ジャンルは「そば・うどん」）。つけ汁が別の器 → つけ麺。
   - 汁の多い麺をパスタにしない。くい違えば見た目を信じる。
4. dishes: 写っている料理ごとに日本語で 1 つずつ（例: 味玉醤油ラーメン、マルゲリータ、抹茶ラテ）。メニューで名前が読めればその名前。
5. summary: 「濃厚な豚骨ラーメンと餃子」くらいの 20 字の一言。
6. kind: meal / cafe / snack / drink。
7. name_seen: 写真（看板・のれん・メニュー・レシート・箸袋・器の名入れ・卓上の紙）から**読めた**店名。読めなければ ""（推測で書かない）。
8. lines: 写真から読めた文字（店名・料理名など）を 10 行まで。無ければ []。
9. お店（eaten_out が true のときだけ）:
   - place_name: どのお店か。name_seen があれば最優先。次に candidates から、料理の種類（cuisine・名前）と距離が合うものを選ぶ（距離が近いだけで料理が合わないお店は選ばない）。candidates が無い・合うものが無いときは、WebSearch で「住所の地名 + 料理の種類 + 写真から分かる特徴（店名の一部、ラーメンの系統、内装など）」を 1〜2 回だけ調べてよい。見つからなければ ""。
   - candidates から選んだときは、candidates の name を一字一句そのまま書く（場所の照合に使う）。
   - place_confidence: 0〜1。店名が写真で読めた・料理とお店がはっきり合う → 0.8 以上。迷う → 0.5 未満。当てずっぽうなら place_name を "" に。
   - place_reason: 30 字くらいの理由（例: 看板の「こもれび」と場所が合った）。
10. unsure: 食事かどうか・ジャンルに自信が無い（暗い・ぼやけている・何の料理か分からない）なら true。true の食事は取り込まない。自信があれば false。

`meals.json` が別のフォルダ（例 `D:\GohanImport\toshu`）にあるときは、そのフォルダの `meals.json`・`meals\<id>.jpg` を読む。
「WebSearch は使わない」と頼まれたら、candidates と写真だけで決める。

## 書き出し
指定のファイルに、1 つの JSON オブジェクトで（UTF-8、Write で）:
```json
{"m00001": {"is_meal": true, "eaten_out": true, "genre": "ラーメン", "dishes": ["スタミナラーメン"], "summary": "…",
            "kind": "meal", "name_seen": "", "lines": [], "place_name": "…", "place_confidence": 0.7, "place_reason": "…",
            "unsure": false}}
```
報告は短く: 書いた件数・お店を決めた件数・自信の低いもの（id と理由、10 件まで）。
