# ごはん帖

ごはんの写真を撮るだけで、「いつ・どのお店で・何を食べたか」が勝手にたまる iPhone のアプリです。
メモは書きません。目的は思い出と「また行きたいお店」を残すことです。

## 動き

1. アプリを開いたとき（と、iOS が許したときにアプリの外で）、前回より後の写真を読む。
   撮ってから1時間たった写真だけを読む（食べている途中で区切らないため）。
2. 端末の中で、写真が食べ物かを見る（Vision の分類）。食べ物でない写真は外に出さない。
3. 40分・250m 以内の食べ物の写真を「1回の食事」にまとめる。
4. 食事の前後に撮った看板・メニュー・レシートの文字を読む（Vision の文字認識）。
5. 写真の位置の近くの飲食店（Apple のマップ）、読めた文字で探したお店、前に行ったお店を候補にする。
6. Claude（`claude-sonnet-5-5`。簡単な写真は `claude-haiku-5-5`）に、料理の写真・手がかりの写真・候補の一覧を見せて、お店・料理名・ジャンルを決めてもらう。
   鍵が無い・月の上限に届いたときは、端末だけで決める（料理名はおおまか）。
7. 自信が低いときだけ「たぶん」の印を付ける。直さなくても困らない。1タップで選び直せる。

## 画面

- 記録: 日ごとの一覧。下に引くと読み直す。
- 地図: 行ったお店のピン（また行きたいはピンク）。
- お店: お店の一覧。お店・料理・ジャンル・メモで探せる。
- 設定: Claude の鍵と月の上限、読む範囲、外した記録。

## 決めてあること（仮の値）

値は `Gohan/Matcher.swift` にまとめてある。どれも試していない仮の値。

- 食べ物とみなす強さ 0.3
- 同じ食事: 40分・250m
- 「たぶん」を付ける自信: 0.7 未満
- Claude の月の上限: $10（設定で変えられる）

## 組み立て

Windows でも、GitHub Actions の macOS で組み立てる（LifeLog と同じ仕組み）。

- `main` に push → テスト・署名なしの IPA・リリース。Secrets が揃っていれば TestFlight へ。
- Secrets: `ASC_KEY_ID`・`ASC_ISSUER_ID`・`ASC_KEY_P8`・`APPLE_TEAM_ID`（LifeLog と同じ値）。
- App Store Connect の「新規 App」は API で作れないので、人が1回作る（バンドル ID `com.off53jub.gohan`）。

## まだしていないこと

- 2人で同じ記録を見る（iCloud の共有）
- 月ごとのまとめ
- 「行きたいけどまだ行っていないお店」のリスト
